# Construction Scene Intelligence

Multimodal computer vision system for construction-site understanding using object detection, segmentation, depth estimation, and vision-language reasoning.

## Planned Features

- YOLOv8 object detection
- SAM2 segmentation
- Depth estimation
- Spatial reasoning
- Scene graph generation
- Vision-language scene understanding
- Safety analysis pipeline
